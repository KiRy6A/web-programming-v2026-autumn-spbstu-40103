# Лабораторная работа 2

## Задание

Вариант 36. Реализовать функцию reverseWords(str), которая переворачивает слова
в строке, сохраняя порядок слов.

Пример: "Hello world" → "olleH dlrow".

По открытому контракту задач: порядок слов сохраняется, символы каждого слова
разворачиваются, в тестовых строках между словами один пробел.

Требования:

- имя export соответствует варианту;
- функция возвращает результат, а не только выводит его в консоль;
- входные массивы не изменяются, если задание явно не требует обратного;
- синхронная задача не возвращает Promise;
- решение работает на граничных случаях, а не только на примерах;
- запрещён хардкод только под известные тестовые значения

## Реализация

1. Регулярное выражение `\S+` находит в строке все последовательности символов,
   не являющихся пробельными (то есть отдельные слова);
2. Каждое найденное слово переворачивается через `[...word].reverse().join("")`
   (разбиение на массив символов с учётом Unicode, разворот массива и склейка
   обратно в строку);
3. Все пробельные разделители между словами (включая несколько пробеловподряд,
   ведущие и завершающие пробелы) остаются без изменений, так как
   `String.prototype.replace` заменяет только совпавшие фрагменты, не затрагивая
   остальную строку;
4. Порядок слов в строке не меняется, а меняется только порядок символов внутри
   каждого слова;
5. Функция не изменяет исходную строку (строки в JavaScript неизменяемы) и
   возвращает новое значение;
6. Пустая строка и строка из одних пробелов обрабатываются корректно и
   возвращаются без изменений, так как в них нетсовпадений с `\S+`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
