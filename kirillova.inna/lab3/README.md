# Лабораторная работа 3

## Задание

Вариант 36. Реализовать функцию findMaxSubarraySum(arr, n), которая находит
максимальную сумму подмассива длины n.

По открытому контракту задач: максимальная сумма непрерывного окна длины n, где
1 <= n <= arr.length; отрицательные суммы допустимы (если все числа
отрицательны, функция корректно возвращает отрицательный результат).

Требования:

- имя export соответствует варианту;
- функция возвращает результат, а не только выводит его в консоль;
- входные массивы не изменяются, если задание явно не требует обратного;
- синхронная задача не возвращает Promise;
- решение работает на граничных случаях, а не только на примерах;
- запрещён хардкод только под известные тестовые значения

## Реализация

Алгоритм - скользящее окно (sliding window) за один проход по массиву:

1. Вычисляется сумма первых n элементов - это начальное значение окна и текущий
   максимум;
2. Окно последовательно сдвигается на один элемент вправо: к текущей сумме
   прибавляется элемент, входящий в окно справа, и вычитается элемент,покинувший
   окно слева (`windowSum += arr[i] - arr[i - n]`);
3. После каждого сдвига сумма окна сравнивается с текущим максимумом, и при
   необходимости максимум обновляется;
4. По завершении прохода возвращается найденный максимум.

Обработка входных данных и краевые случаи:

- если n не является целым числом либо выходит за границы [1, arr.length], то
  выбрасываем исключение;
- если первый аргумент не массив, то выбрасываем исключение;
- функция корректно работает с отрицательными числами (например, для массива из
  одних отрицательных чисел возвращается наименьшая по модулю отрицательная
  сумма среди окон длины n);
- исходный массив arr не изменяется

Импортируйте именованный export из `solution.js` как ES module.
