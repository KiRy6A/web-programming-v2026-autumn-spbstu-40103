# Лабораторная работа 3

## Задание

Вариант 4.

Реализуйте функцию mergeArrays(arr1, arr2), которая объединяет два массива,
удаляя дубликаты.

## Реализация

Распаковываем два массива, кладем их в set, чтобы убрать дубликаты. Set
преобразуем в итоговый массив. Ограничение - работает на примитивных типах, т.к.
чего то типа equals и hashCode в js я не нашел. Можно было бы передать в функцию
свой компаратор для таких ситуаций, но тогда поменялся бы контракт.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
