# Лабораторная работа 2

## Задание

Вариант 4.

Написать функцию convertBase(num, fromBase, toBase), преобразующую число между
системами счисления.

## Реализация

Через parseInt преобразуем в десятичную систему, потом в toString указываем
желаемое основание и получаем ответ.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
