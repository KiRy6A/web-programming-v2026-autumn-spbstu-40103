# Лабораторная работа 4

## Задание

Вариант 13. Игры и платформы.

Создать класс `Game` с полями `title` (название игры), `platforms` (массив
платформ) и `releaseYear` (год выпуска). Реализовать методы
`addPlatform(platform)`, `removePlatform(platform)` и геттер `platformCount`.

Для коллекции игр реализовать пять функций:

- `groupGamesByReleaseYear(games)` — группировка игр по году выпуска;
- `getUniquePlatforms(games)` — получение списка уникальных платформ;
- `findGamesByPlatform(games, platform)` — поиск игр на заданной платформе;
- `groupGamesByPlatformCount(games)` — группировка по количеству платформ;
- `findGamesReleasedAfter(games, year)` — поиск игр, выпущенных после заданного
  года.

Разработать интерфейс с карточками игр, формой добавления игры, добавлением и
удалением платформ и удалением игр. Операции добавления и удаления должны
выполняться асинхронно через `Promise` и `setTimeout`. Интерфейс должен
обновляться без перезагрузки страницы, а данные — сохраняться в `localStorage`.

## Реализация

Приложение написано на HTML, CSS и JavaScript без сторонних библиотек.

- `index.html` — форма ввода названия игры, года выпуска и платформы, кнопки
  управления и контейнер карточек.
- `model.js` — класс `Game`, функции работы с коллекцией и асинхронные функции
  `addGame` и `removeGame`.
- `main.js` — обработчики событий, создание карточек, сохранение и загрузка
  данных.
- `styles.css` — оформление формы, кнопок и карточек. Список карточек построен
  на Flexbox с переносом строк.

При добавлении игры проверяются непустое название, год выпуска не раньше 1952
года и отсутствие игры с таким же названием. Сравнение названий учитывает
регистр. Добавление игры выполняется по событию `submit` формы.

Каждая карточка показывает название игры, год выпуска, список платформ и
собственную кнопку удаления. Для изменения платформ нужно ввести точное название
существующей игры и название платформы, затем нажать соответствующую кнопку. При
добавлении платформ повторяющиеся значения удаляются с помощью `Set`.

После завершения операции вызываются сохранение данных и перерисовка карточек.
Список хранится в `localStorage` под ключом `games` в формате JSON. При загрузке
страницы функция `loadGames` восстанавливает из сохранённых объектов экземпляры
`Game`.

Для автопроверки используются атрибуты `data-testid`: `entity-form` у формы,
`entity-list` у списка, `entity-card` у карточек и `delete-entity` у кнопок
удаления внутри карточек.

## Запуск

Откройте файл `parfenov.yaroslav/lab4/index.html` в браузере. Установка
зависимостей и сборка приложения не требуются.

Чтобы добавить игру, заполните название и год выпуска, при необходимости укажите
платформу и нажмите «Добавить игру». Для удаления используйте кнопку «Удалить»
внутри нужной карточки. Для изменения платформ введите название существующей
игры и название платформы, затем нажмите «Добавить платформу» или «Удалить
платформу».

Список игр сохраняется в `localStorage` и восстанавливается при повторном
открытии страницы в том же браузере.
