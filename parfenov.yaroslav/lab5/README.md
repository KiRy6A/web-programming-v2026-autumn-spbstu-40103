# Лабораторная работа 5

## Задание

Вариант 13 - чат.

Одностраничное React-приложение для обмена сообщениями. Пользователь вводит имя
и текст сообщения, после чего сообщение появляется в истории вместе с именем
автора и временем отправки.

История сообщений сохраняется в `localStorage`, восстанавливается после
перезагрузки страницы и может быть полностью очищена пользователем.

## Реализация

Приложение реализовано с помощью функциональных React-компонентов:

- `App` хранит состояние истории и выполняет добавление и очистку сообщений;
- `ChatMessageForm` содержит поля имени и сообщения, а также кнопки отправки и
  очистки;
- `ChatMessages` отображает историю или приглашение написать первое сообщение и
  синхронизирует состояние с `localStorage`;
- `MessageCard` отображает время, автора и текст отдельного сообщения;
- `HeaderCard` отображает заголовок приложения.

Для каждого сообщения создаётся уникальный идентификатор. Атрибуты `data-testid`
соответствуют открытому контракту варианта.

## Запуск

В каталоге лабораторной выполните:

```bash
npm install
npm run dev
```
